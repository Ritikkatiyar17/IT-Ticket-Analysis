# IT-Ticket-Analysis
# Analyzed 97,000+ IT support tickets to uncover trends in volume, resolution time, and performance. Built Excel dashboards, identified recurring issues, and recommended process improvements, employee training, and software updates to enhance efficiency and service quality.

I worked on IT Ticket Analysis using Excel & The goal was to analyze IT support ticket data to evaluate agent performance and improve operational efficiency. 
My task was to analyze ticket data such as priority, issue type, assigned agent, resolution time, and status to identify performance patterns and inefficiencies.

I used Excel tools like Pivot Tables, Pivot Charts, and formulas to clean and analyze the data and created an interactive dashboard to track KPIs such as total tickets, resolved and pending tickets, and average resolution time per agent. From the analysis, I identified differences in agent performance and delays in ticket resolution.

Based on these insights, I recommended setting benchmarks for resolution time, balancing workload among agents, and improving ticket categorization and assignment processes.
