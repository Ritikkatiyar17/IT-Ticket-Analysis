# 📊 IT Ticket Analysis Dashboard

An end-to-end **Data Analytics** project using **Microsoft Excel** to analyze IT support tickets, evaluate service performance, monitor operational KPIs, and generate actionable insights to improve support efficiency and customer satisfaction.

---

## 🎯 Project Objective

The objective of this project is to:

- Analyze IT support ticket trends and service performance.
- Evaluate agent productivity and operational efficiency.
- Monitor SLA compliance and resolution time.
- Track customer satisfaction (CSAT) and ticket backlog.
- Generate data-driven recommendations to optimize support operations.

---

## 🛠️ Tech Stack

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

---

## 📂 Dataset

- **Records:** 97,498 IT Support Tickets
- **Support Agents:** 50
- Ticket Details
- Severity & Priority
- Request Categories
- Resolution Metrics
- SLA Status
- Customer Satisfaction (CSAT)

## ✨ Key Features

- Data Cleaning & Validation

- Interactive Excel Dashboard
- Ticket Trend Analysis

- Agent Performance Analysis
- Business Insights & Recommendations

## 📊 Dashboard KPIs

- Total Tickets
- Total Support Agents
- Average Resolution Time
- First Response Time
- SLA Compliance
- Ticket Backlog
- Customer Satisfaction (CSAT)
- Agent Performance

---

## 📈 Key Insights

- Analyzed 97K+ IT support tickets across 50 support agents.
- Normal severity tickets accounted for the highest ticket volume.
- System-related requests represented the largest share of support tickets.
- Customer satisfaction remained above 4.0 while maintaining operational performance.
- Identified peak ticket periods and workload patterns to support resource planning.

---

## 💡 Business Recommendations

- Optimize workload distribution across support agents.
- Prioritize high-volume request categories to improve service efficiency.
- Monitor SLA compliance to reduce ticket resolution time.
- Leverage KPI tracking to enhance customer satisfaction and operational performance.
